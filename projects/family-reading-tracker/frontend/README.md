# Reading Tracker frontend

React/Vite frontend for the Book Worm Buddies rebuild. See the [project README](../README.md) for credits, setup, and limitations.

- `npm ci` — install locked dependencies.
- `npm run dev` — start with a local backend proxy.
- `npm run build` — build the regular frontend.
- `npm run build:demo` — build the fictional-data demo for `/demos/reading-tracker/`.
- `npm run lint` — check frontend source.
