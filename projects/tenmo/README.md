# TEnmo — project overview

A Tech Elevator educational payment-service project with a Java command-line client, Spring Boot REST API, and PostgreSQL/JDBC persistence.

Project work covered account access, JWT authentication, transfer workflows, and approval/rejection states. It provided practice connecting a client to API endpoints and modeling transactions in a relational database.

This is an overview, not a source-code release or a live payment service. The current portfolio publication focuses on the [Kalshi monitor](../kalshi-brti-monitor) and [Family Reading Tracker rebuild](../family-reading-tracker).
